# DeskPet

Windows 桌面宠物项目，已完成基础桌宠、键鼠统计、成长、角色外观、背包场景和基础工具箱。产品需求与开发规划见 `DeskPet.md`，任务范围和进度见 `TASKS.md`。

## 开发环境

- Windows 10/11 x64；本轮在 Windows x64 上验证。
- Node.js 24 LTS 和 npm（本轮使用 Node.js 24.15.0、npm 11.12.1）。依赖最低要求为 Node.js 22.13.0；建议使用 Node.js 24。
- 首次运行和打包需要网络下载 Electron Windows 二进制文件。网络使用系统代理而 Node 未自动识别时，请在当前 PowerShell 会话中配置相应的 `HTTPS_PROXY`、`HTTP_PROXY` 和 `NODE_USE_ENV_PROXY=1`，再重试；不要将代理凭据提交到项目中。

## 安装与运行

```powershell
npm ci
npm start
```

## 检查和测试

```powershell
npm run typecheck
npm run lint
npm run format:check
npm test
```

`npm run format` 可自动格式化项目文件。

## 打包

```powershell
npm run package
```

生成的 Windows 应用目录位于 `out/`。`npm run make` 可进一步生成 Squirrel 安装包；此命令是否验证，以 `TASKS.md` 的记录为准。

## 架构

- `src/main`：窗口生命周期及系统能力。
- `src/preload`：经 `contextBridge` 暴露最小化桌面接口。
- `src/renderer`：React 界面。
- `src/shared`：跨进程共享类型。
- `src/features`、`src/tools`、`src/services`：游戏功能、生产力工具和共享服务。
- `public/assets`、`docs`：正式美术资源与项目文档。

渲染进程启用了沙箱和上下文隔离，并关闭 Node 集成；所有本地数据通过主进程校验后写入 Electron 用户数据目录。

## 桌宠操作

拖动桌宠可以移动窗口，位置在移动后保存。通过系统托盘菜单显示或隐藏桌宠、切换置顶或完全点击穿透，以及退出程序；双击托盘图标可显示桌宠。透明区域默认穿透鼠标，完全穿透开启后可从托盘关闭。重复启动会显示已有桌宠。

## 键鼠次数统计（TASK-003）

统计默认暂停。第一次从托盘选择“启用统计”或按 `Ctrl+Alt+Shift+P` 时，应用会说明监听范围并请求确认。启用后托盘显示本次运行的键盘按下和鼠标点击汇总；相同入口可随时暂停。锁屏或休眠时自动停止监听，恢复后按上次选择继续。统计不保存按键内容、鼠标位置或输入顺序，每日汇总会保存到本机 SQLite 数据库。

打包后可运行 `out/DeskPet-win32-x64/DeskPet.exe --input-hook-smoke-test` 验证打包程序能加载原生模块。退出码 0 表示该项验证通过；它不模拟真实输入。普通运行不需要此参数。

## 本地统计（TASK-004）

从托盘选择“查看统计”，可查看今日、累计和最近 7 天和 30 天的键盘、鼠标次数与聚合活跃时间，导出 CSV 或确认清除全部统计。数据库保存在 Electron 用户数据目录的 `statistics.sqlite`；键鼠统计只保存日期、汇总次数和活跃秒数，不保存按键内容或鼠标位置。每五秒、暂停及退出时写入；异常退出可能丢失尚未写入的数秒数据。清除只影响已统计次数，不改变监听授权、开关或成长数据。

## 成长系统（TASK-005）

启用统计后，新增键鼠操作按 25 次键盘或 8 次鼠标兑换 1 点经验，每日本来源最多获得 200 点；完成专注每次获得 10 点经验，每日另有 50 点上限。统计窗口可查看等级和经验，奖励会原子发放为星星币、物品、角色或场景。原有历史统计不会追溯兑换，清除统计不影响成长记录。

## 外观、场景与工具（TASK-006–009）

从托盘打开“查看统计”，可选择已解锁的角色、透明/森林场景及已获得的头部和颈部饰品，并查看背包或执行确定性合成。桌宠使用原创 SVG 资源和统一状态机。

工具箱可分别启停番茄钟、桌面便签、久坐提醒和今日总结。番茄钟支持专注/休息、暂停/继续、到时通知和声音开关；便签支持自动保存、颜色、独立窗口和置顶；久坐提醒支持自定义间隔、静音时段、延迟和休息重置。数据均只保存在本机。
