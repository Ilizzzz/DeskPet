# DeskPet

Windows 桌面宠物 + 成长养成 + 生产力工具。完全本地运行、无账号、离线可用。
当前版本 `1.1.1`，产品需求与长期规划见 `DeskPet.md`，任务与验收记录见 `TASKS.md`。

## 1.1.1 修复

- 修复 1.1.0 安装包在干净电脑上启动键鼠统计时提示“键鼠监听不可用”：原生键鼠模块
  `uiohook-napi` 之前没有被复制进安装包（开发机因为能找到仓库 `node_modules` 而误报通过）。
- 新增 `npm run check:package` 校验打包产物必须包含并解包原生模块；发布前还应在
  **项目目录之外**复制一份应用目录运行 `--input-hook-smoke-test` 做干净环境验证。
- 监听启动失败不再弹错误框阻断：统计保持暂停，桌宠和工具箱继续可用；设置页显示原因
  并支持重试，诊断日志位于 `%APPDATA%\DeskPet\input-diagnostics.log`。

## 1.1.0 主要变化

- **美术升级**：角色、装扮、场景装饰与界面图标统一替换为 Microsoft Fluent Emoji
  3D 素材（MIT，可商用），共 8 个伙伴、25 件五槽位装扮、8 个场景；旧手绘 SVG 全部移除。
- **拖动修复**：去掉点击触发的摸头/跳跃动画和覆盖在桌宠上的交互按钮；整只桌宠都可以拖动，
  单击显示台词气泡，双击打开控制中心，右键打开快捷菜单。
- **等级解锁**：工具、伙伴、场景和装扮全部改为按等级解锁，并新增签到、12 个成就、
  材料兑换、高级装扮合成与分解。
- **没有每日上限**：删除键鼠与专注的每日经验上限；专注每次还会给星星币，并按次数给星光碎片。
- 新增 4 个工具：待办清单、喝水提醒、倒计时、纪念日；控制中心界面整体重做。

## 开发环境

- Windows 10/11 x64；本轮在 Windows x64 上验证。
- Node.js 24 LTS 和 npm（本轮使用 Node.js 24.15.0、npm 11.12.1）。依赖最低要求为 Node.js 22.13.0；建议使用 Node.js 24。
- 首次运行和打包需要网络下载 Electron Windows 二进制文件。网络使用系统代理而 Node 未自动识别时，请在当前 PowerShell 会话中配置相应的 `HTTPS_PROXY`、`HTTP_PROXY` 和 `NODE_USE_ENV_PROXY=1`，再重试；不要将代理凭据提交到项目中。
- 如果 `github.com` 无法直连导致 `npm run package` 报 `fetch failed`，可临时设置
  `$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'` 后重试。

## 打包

```powershell
npm run package
npm run check:package
npm run make
```

生成的 Windows 应用目录和 Squirrel 安装包位于 `out/`。构建前会自动生成应用图标。
`check:package` 会确认原生键鼠模块已包含并解包；发布前还应把
`out/DeskPet-win32-x64` 复制到项目目录之外运行 `--input-hook-smoke-test`，
避免开发机的 `node_modules` 掩盖打包缺失。

发布说明、隐私说明、已知限制、卸载与第三方许可证分别见
`docs/RELEASE_NOTES.md`、`docs/PRIVACY.md`、`docs/KNOWN_ISSUES.md`、
`docs/UNINSTALL.md` 和 `docs/THIRD_PARTY_NOTICES.md`；美术素材与授权登记见
`docs/ASSET_GUIDE.md`。

## 架构

- `src/main`：窗口生命周期、托盘、拖动、IPC 路由和系统能力。
- `src/preload`：经 `contextBridge` 暴露最小化桌面接口。
- `src/renderer`：桌宠渲染（`App.tsx` + `pet.css`）与控制中心页面。
- `src/shared`：跨进程共享类型、奖励结构和窗口尺寸常量。
- `src/features`、`src/tools`、`src/services`：游戏成长、签到/成就/合成、生产力工具和共享服务。
- `src/data/catalogs`：角色、装扮、场景、解锁、成长、成就、合成和工具元数据。
- `public/assets`、`docs`：正式美术资源与项目文档。

渲染进程启用沙箱和上下文隔离，并关闭 Node 集成；所有本地数据通过主进程校验后写入
Electron 用户数据目录。数据库架构版本为 15，旧版本会自动迁移。

## 桌宠操作

- **拖动**：按住桌宠任意位置即可移动，主进程跟踪光标移动窗口；拖动结束后保存位置。
- **单击**：显示一句随机台词（不触发跳跃/摸头动画，不阻塞拖动）。
- **双击**：打开控制中心。
- **右键**：打开快捷菜单，可打开控制中心、显示/隐藏桌宠、切换键鼠统计、置顶、
  完全点击穿透或退出。
- 托盘菜单可显示/隐藏桌宠、切换置顶和点击穿透；双击托盘图标可显示桌宠。
  透明区域默认穿透鼠标，完全穿透开启后可从托盘或右键菜单关闭。

## 成长与解锁

- 键盘每 25 次、鼠标每 8 次各获得 1 EXP，余数独立跨批次保留；**没有每日经验上限**。
- 完成一次专注获得 10 EXP + 2 星星币；每累计完成 3 次专注额外获得 1 星光碎片。
- 升级所需经验：`100 + 30 × (L - 1) + 5 × (L - 1)²`，最高 1000 级。
- 等级奖励、签到、成就、专注和分解都会获得星星币/星光碎片。
- 伙伴（8）、场景（8）、装扮（25，头部/颈部/面部/手持/背部）按等级自动解锁；
  工具从 2 级起依次解锁（今日总结 1 级可用）。
- 每日签到：星星币随连续天数递增，每天 1 星光碎片，每连续 7 天额外 2 碎片。
- 12 个成就覆盖输入、专注、等级、收藏、合成、签到和场景/伙伴收集，奖励需手动领取且只发一次。
- 合成工坊：7 条材料兑换（1 碎片 + 15 星星币换普通装扮）和 14 条高级配方；
  分解未穿戴装扮可得 10 星星币，稀有/史诗额外 1、传说额外 2 星光碎片。
- 旧版本数据会无损迁移：小狐狸替换为同色系小老虎，`hat_blue/hat_star/scarf`
  迁移为新装扮 ID。

## 桌面工具箱

- 今日总结：键鼠、活跃时间、经验、等级、专注和今日奖励汇总。
- 番茄钟：专注/休息、暂停/继续、到时通知、声音开关和专注统计。
- 桌面便签：纯文本自动保存、颜色、独立桌面窗口和置顶。
- 久坐提醒：提醒间隔、离开重置、静音时段、延迟和“我已休息”。
- 待办清单：本地增删改、完成状态。
- 喝水提醒：定时提醒、每日目标与杯数记录。
- 倒计时：给重要时刻设置倒计时，到点系统通知。
- 纪念日：记录日期并按最近的下一次日期排序。

工具在达到解锁等级前显示为锁定，达到等级后沿用用户自己的启停偏好。所有工具数据只保存在本机。

## 数据与隐私

键鼠统计默认暂停，首次启用需明确确认。DeskPet 只保存聚合次数、活跃秒数和用户主动输入的
本地数据；不读取或保存按键内容、输入文本、鼠标坐标、窗口标题或访问的网站；不包含登录、
云同步、遥测、广告或在线分析。清除和重置入口位于控制中心“设置与隐私”。
