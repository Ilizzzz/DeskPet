# 美术资源指南（TASK-011）

DeskPet 的宠物、装扮、场景装饰与界面图标统一来自 **Microsoft Fluent Emoji**（3D 风格 PNG），
许可证为 MIT，可随项目免费分发；完整许可证见
[`public/assets/licenses/fluent-emoji-LICENSE.txt`](../public/assets/licenses/fluent-emoji-LICENSE.txt)，逐个文件的原始地址与校验值见
[`public/assets/licenses/sources.json`](../public/assets/licenses/sources.json)。

资源约定：

- 统一 256×256 RGBA PNG、透明背景，文件名 snake_case，路径必须与 `src/data/catalogs/*.ts` 中的 `assets/...png` 完全一致。
- `characters/` 8 个角色、`items/` 25 件五槽位装扮、`decor/` 24 个场景装饰、`icons/` 22 个界面/工具/指标图标。
- 饰品定位由 `src/data/catalogs/anchors.ts` 的锚点控制（256 画布坐标），场景布局由 `src/data/catalogs/scenes.ts` 控制。
- 校准预览：[`docs/previews/anchors-preview.png`](previews/anchors-preview.png)、[`docs/previews/scenes-preview.png`](previews/scenes-preview.png)。
- 校验脚本：`npm run validate:assets`（检查引用文件存在、PNG 签名、256×256、透明通道与登记完整性）。

## 使用说明

- 角色、装扮与图标都是透明 PNG，直接按目录数据引用；不要修改文件名或路径。
- 场景背景图（整幅插画型素材）：`night_stars.png` 用于星空露台、`sunset.png` 用于海边黄昏、
  `cityscape_dusk.png` 用于城市黄昏，其余场景使用 CSS 渐变 + 透明装饰。
- `bridge_night.png` 在温馨书房中作为墙面挂画使用；`shooting_star.png` 为保留素材，当前未用于场景。
- `keyboard.png`、`mouse.png`、`clock.png` 供首页键鼠/专注指标卡使用（TASK-011 追加）。
- 新增或替换素材时必须同时更新本文件、`public/assets/licenses/sources.json` 与
  `docs/THIRD_PARTY_NOTICES.md`，并运行 `npm run validate:assets`。
