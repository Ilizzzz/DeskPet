# DeskPet 隐私说明

DeskPet 1.1 是本地优先的 Windows 桌面应用，不要求账号，核心功能离线运行，默认不会上传用户数据。

## 键鼠统计

键鼠统计默认暂停，只有用户明确启用后才会启动全局监听。DeskPet 只保存：

- 每日本地日期；
- 键盘按下次数；
- 鼠标点击次数；
- 由聚合批次估算的活跃秒数。

DeskPet 不读取或保存按键内容、输入文本、按键顺序、鼠标坐标、鼠标轨迹、窗口标题、应用名称、文件内容、浏览器记录或访问的网站。

统计可随时在控制中心、托盘或 `Ctrl+Alt+Shift+P` 暂停。锁屏和系统休眠期间监听会停止。

## 其他本地数据

成长、奖励、背包、外观、场景、签到、成就、合成记录、待办、倒计时、纪念日、喝水记录、
番茄钟、便签、久坐提醒和应用偏好存放在 Electron 用户数据目录。便签和待办内容只来自
用户主动输入，不会从全局监听中生成。

## 导出与删除

控制中心的“设置与隐私”页面可以：

- 导出键鼠统计 CSV；
- 只清除键鼠统计，保留成长数据；
- 重置全部本地数据和应用偏好。

卸载程序默认保留用户数据，便于重装恢复。如需彻底删除，请在卸载前使用“重置全部本地数据”，或按 [UNINSTALL.md](UNINSTALL.md) 手动删除用户数据目录。
