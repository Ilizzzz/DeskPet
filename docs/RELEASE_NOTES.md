# DeskPet 1.0.0 发布说明

发布日期：2026-10-28

## 首个基础版本

- 透明置顶桌宠、拖动、托盘、点击穿透、单实例和位置恢复；
- 可选的全局键鼠聚合统计、7/30 天趋势、CSV 导出和本地清除；
- 输入与专注经验、等级曲线、奖励、星星币和解锁；
- 小猫、小狐狸、头部/颈部饰品、背包、确定性合成和两种场景；
- 番茄钟、桌面便签、久坐提醒和今日总结；
- 首次启动引导、隐私控制、动画开关、开机启动和本地数据重置；
- Windows x64 Squirrel 安装包和应用图标。

## 数据与兼容性

- 所有用户数据默认保存在本机；
- 数据库架构版本为 14，旧版本会自动向前迁移；
- 目标系统为 Windows 10/11 x64；
- 本版本没有自动更新功能，升级采用手动下载安装包。

发布前人工验收项和限制见 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)。
