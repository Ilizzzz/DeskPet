# TASK-011 素材清单

统一来源：**Microsoft Fluent Emoji**（MIT License）。
原始仓库：https://github.com/microsoft/fluentui-emoji
下载地址模板：`https://raw.githubusercontent.com/microsoft/fluentui-emoji/main/assets/<Emoji Name>/3D/<emoji_snake>_3d.png`

要求：

- 只下载 3D 风格的 PNG（256×256，透明背景）。
- 本地文件名使用 snake_case，放到下列路径；路径必须与目录文件中的引用完全一致。
- 在 `docs/ASSET_GUIDE.md` 与 `docs/THIRD_PARTY_NOTICES.md` 登记来源、作者、许可证、
  下载日期和修改说明；在 `public/assets/licenses/` 保存 MIT 许可证原文。
- 不得使用其他来源或未登记素材；影视/游戏角色一律不使用。
