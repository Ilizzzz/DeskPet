# DeskPet Version 2 规划与任务清单

状态：核心范围已实现，版本号为 2.0.0。P0、P1 任务与自动化验收已经完成；真实 Windows 10/11 干净环境、真实 V1 用户数据库副本、多显示器和高 DPI 等发布验收仍保留为人工检查项。P2 是后续候选，不属于本次交付。

## 目标与现状

让日常使用带来可期待的收获，以统一的二次元 2D 美术、自然的动作和逐步成长的内容提升陪伴感。核心循环为：**正常使用键盘 → 获得装扮 → 穿戴或分解重复品 → 积攒星星币 → 兑换心仪装扮**。

当前 1.1.2 中，角色、场景及装扮达到等级后自动发放；部分相同装扮又可用星星币、星光碎片兑换或由配方合成，且合成产物也受等级限制。因此兑换和合成往往只能增加已经获得的同款数量，难以形成明确的追求。现有分解已支持未穿戴装扮，统一返还 10 星星币，稀有及以上额外返还碎片；它不是从零开始的新功能，需要围绕重复品、初级帽子和新经济重新设计。

## 已实现规则

### 获得方式与成长分工

- [x] 角色、地面场景及专属里程碑装扮可按等级自动获得；等级奖励还可提供星星币和陪伴表现。每件装扮明确归入「等级专属赠送」或「掉落 / 兑换」之一，避免同一件同时作为必得等级奖励和付费目标。
- [x] 新账号保留默认伙伴与透明场景，并在新手引导中直接赠送一件蓝色棒球帽，确保开局即可体验穿戴。此帽可再次掉落。
- [x] 除新手赠品与新增的等级专属装扮外，其他装扮通过掉落或星星币兑换获得；现有 25 件装扮都保留明确的兑换价格，包括尚未进入掉落池的装扮。掉落和兑换是同一目标的随机与确定性替代路径，获得任一途径均可直接穿戴，不再需要二次购买或等级许可。
- [x] 成长路线显示伙伴、地面场景、专属装扮、动作和货币等奖励；装扮图鉴显示明确来源及「已拥有」状态。基础工具继续可用，扩展功能可按等级开放，不锁住核心使用能力。
- [x] 移除现有的普通材料兑换和高级装扮合成入口，避免为增加同款数量而绕圈消耗；保留历史记录。未来若重做合成，应产出有独立价值的限定装扮并单独立项，不属于本次必做。

- [x] 直接发到背包并展示结果，不设需打开的付费宝箱；公开每件概率。允许重复，重复件可穿戴保留或分解。常规掉落没有每日上限；禁止为奖励引导用户刻意刷键或延长工作。

### 货币、兑换与分解

- [x] Version 2 的新经济统一使用星星币。等级、专注、签到、成就及分解继续提供星星币；重新平衡各来源，保留现有经验计算，避免把休息或签到变成义务。
- [x] 旧星光碎片余额原样保留，提供用户主动选择的单向兑换：1 碎片 = 20 星星币，兑换前显示数量与结果并确认；历史碎片奖励保持记录，不重复发放。新奖励和新商品不再使用碎片；旧余额为零时仍可解释历史记录。
- [x] 建立按稀有度的首轮基准价格：普通 80、稀有 180、史诗 450、传说 1,000 星星币；对应分解返还 10、25、60、120 星星币。具体物品价格可配置，必须小于等于可负担的长期目标，并保证分解返还低于其直接兑换价，防止循环刷币。
- [x] 明确支持初级头饰：蓝色棒球帽和花朵发饰各可分解为 10 星星币；淑女礼帽和魔术礼帽按稀有装扮各返还 25。背包要显示每件的数量和实际返还，重复掉落后可逐件分解。
- [x] 默认保护每款最后一件；允许用户明确关闭保护并确认分解最后一件，明确提示该款将不能穿戴，之后可通过掉落或兑换重新获得。穿戴中的那一件始终保留，若有多件则允许分解多余数量。
- [x] 兑换仅允许当前未拥有的可兑换装扮，分解和兑换前展示消耗、所得及剩余余额；所有扣除、发放与记录必须同一事务完成，失败全部回滚。等级专属装扮若分解了最后一件，曾经获得过该装扮的用户可按其价格兑换取回；不会因兑换前达到等级而自动重新发放。
- [x] 测算例如每天 3,000 次键盘输入的期望掉落、重复品分解收益，以及签到、专注、升级等来源与各档兑换所需时间；覆盖新用户、已有大量库存和低频用户，记录测算假设、结果与调整依据。

### 二次元美术与地面场景

- [x] 整体改为统一的二次元、手绘感 2D 风格：明确角色比例、线条、配色、视角、透明画布及动画规范。优先以猫作为纵向试做，确认视觉风格后再扩展其他伙伴，不继续沿用立体 emoji 风格作为目标。
- [x] 装饰与宠物统一视角和画风，按角色、方向、动作及帧配置头部、颈部、面部、手持、背部的锚点、旋转、缩放和遮挡层级；检查帽子贴合头顶、眼镜贴合眼睛等，避免漂浮和穿模。无法适配的组合暂不开放并说明，不能默默错位。
- [x] 场景改为透明背景上的小范围地面物件，如圆地毯、草地垫、木地板片或坐垫；与宠物脚底相接，不使用突兀的方形背景或大面积遮挡桌面。保留无地面装饰选项，明确旧场景到新地毯的对应关系并保留用户已解锁状态。
- [x] 制定角色与头饰的适配矩阵，先完成代表性伙伴、每种槽位、站立和关键动作的预览，再扩展全量；美术资源经许可审核并登记后才引入。缺少可用素材时可原创绘制或生成再人工校正，不把外部现成素材直接混搭当作最终风格。

### 缩放、屏幕边缘与输入动作

- [x] 宠物提供 25%、50%、75%、100%、125% 五档缩放，默认 100%；控制中心和托盘提供入口，支持恢复默认并记住选择。宠物、装饰、地面、动作锚点和交互命中区域同步缩放；可访问的设置入口保持正常尺寸。
- [x] 根据所在显示器的可用工作区实现边缘吸附：拖动结束时距离底边或左右边缘进入可配置阈值才吸附，超出阈值可自由放置；可在设置中关闭。多显示器、任务栏位置、DPI、切换屏幕、缩放和屏幕拔出后保持可见，重启恢复时重新校正。
- [x] 底边提供坐下、伸腿或趴沿等动作，左右边缘提供抓边、探头等朝向匹配的动作；动作有稳定落点，不让宠物或饰品被屏幕裁掉。拖动、升级及用户交互优先，离开边缘后恢复正常待机；动画关闭时保持静态可用。
- [x] 键盘输入触发轻量打字、专注或点头动作，鼠标点击触发好奇、挥手等不同反馈；依据现有监听授权及暂停状态，只传递限频后的输入类型或聚合状态。连续输入时合并反馈并设置冷却，不能每次输入都打断动画、闪烁或干扰工作；提供独立开关并遵循总动画开关。
- [x] 输入动作与边缘动作纳入现有状态机，明确拖动、升级、主动交互、边缘和输入动作的优先级、持续时间与恢复行为；无对应动作素材时平稳回退待机。

- [x] 审查首页、侧栏、首次引导和设置中的产品文案，移除反复强调技术或数据存储方式的宣传语，例如「本地优先」「数据不会自动上传」「所有记录只保存在这台电脑」；改为介绍用户能使用的功能。监听授权、清除数据和卸载等实际决策所需信息，在对应操作处准确、简洁说明。

## 开发任务与验收

### P0：经济闭环与迁移

- [x] **V2-001 规则落地**：整理装扮来源、星星币产出与价格表，逐项检查 25 件现有装扮、新增专属装扮及每种稀有度均有可达路径；确认首轮参数后再实施。
- [x] **V2-002 键盘掉落结算**：在已有键鼠聚合和 SQLite 结算边界中接入独立掉落进度；进度、随机结果、库存及奖励记录同一事务提交。失败重试、重启和重复处理不能重复发奖，跨批次多个阈值与余数准确。
- [x] **V2-003 背包和货币**：调整分解、兑换、碎片转换与钱包，校验库存、装备、余额和参数；实现预览、确认、保护及完整回滚。状态变化即时同步外观和图鉴。
- [x] **V2-004 版本迁移**：从数据库版本 15 制定版本化、可重复执行的迁移，保留等级、经验、统计、伙伴、场景、所有库存数量、穿戴、货币和碎片。历史等级奖励不撤销、不重新发放；已拥有的 V1 装扮在迁移时原样保留，原 V1 装扮今后不再按等级自动发放；旧自动发放标记不因改规则导致补发。新增等级专属奖励另设幂等标记，符合条件的老玩家补领一次。新手赠帽只针对新账号，老账号不额外赠送或扣除。
- [x] **V2-005 规则切换**：掉落从升级后新产生的有效键盘次数开始，旧统计不追溯掉落；初始进度为 0。清除统计不清除独立掉落进度或库存；全部数据重置才恢复新账号状态，界面清楚说明。历史签到和成就领取状态保留；未领取奖励按明确显示的 V2 规则领取一次。旧合成成就保留已领取状态和历史计数，未完成者改为等价值的新目标并在迁移说明中写明，避免无法完成或重复领奖。
- [x] **V2-006 安全与隐私**：主进程执行抽取和事务；Preload 只暴露最小固定接口，校验调用来源、物品 ID、数量及状态。只使用已有聚合键盘次数，不记录按键内容、顺序、窗口或输入轨迹，数据仍在本地用户数据目录。

### P1：可理解、可期待的体验

- [x] **V2-007 成长与外观界面**：展示距离下次掉落的进度、掉落结果、各物品概率、来源、兑换价、分解收益和心愿进度；首次介绍新规则及旧货币处理。奖励提示可关闭或合并，不能干扰办公。
- [x] **V2-008 收藏图鉴**：区分当前拥有与曾经获得；分解最后一件后保留「曾获得」记录但明确不可穿戴。显示未获得物品与确定性获取路径，不以颜色作为稀有度唯一标识。
- [x] **V2-009 陪伴小惊喜**：新增不影响奖励的轻量掉落反馈，例如宠物短暂庆祝或一句台词；遵循现有动画关闭设置，不新增强制提醒或活跃惩罚。
- [x] **V2-010 数值评估**：使用固定随机种子的模拟覆盖概率、长期重复率和各类用户获得节奏；对照预期结果调整配置并记录。公开概率必须与实际抽取一致。
- [x] **V2-014 二次元美术及地面场景**：完成猫的风格样稿与装饰适配预览，再扩展伙伴、装饰和地毯；审核资源许可，完成旧场景迁移与全角色关键动作检查。
- [x] **V2-015 宠物缩放**：实现 25%、50%、75%、100%、125% 档位、持久化和入口；校验不同缩放比例下的视觉、穿戴、地面、交互区域与屏幕边界。
- [x] **V2-016 边缘吸附与动作**：实现可关闭的底部和左右边缘吸附，适配不同朝向的专属动作，覆盖显示器切换、任务栏、多 DPI、拖动及失效显示器恢复。
- [x] **V2-017 键鼠动作**：为键盘和鼠标分别增加限频、可关闭的动作反馈，并与桌宠现有状态机协调；监听暂停或动画关闭时不触发。
- [x] **V2-018 成长内容扩展**：设计并落实新增等级专属装饰、地面场景、动作和轻量功能，明确每项来源及解锁节奏；补领和记录均须幂等，兑换、掉落与等级赠送的关系清晰。
- [x] **V2-019 文案整理**：逐页移除重复的开发视角数据宣传，重写首页、侧栏和引导文案；在授权、清除和卸载的操作上下文保留必要说明。
