# TASK-011 历史设计摘要

状态：已归档。本文只记录 1.1.0 阶段的演进背景，不能作为当前实现契约。

## 当时的目标

- 把占位角色扩展为 8 个伙伴、25 件装扮和 8 个场景。
- 修复桌宠拖动与点击交互冲突。
- 扩展签到、成就、工具和五槽位外观。
- 将数据库升级到 v15，并迁移旧角色和装扮 ID。
- 用统一素材来源替换早期手绘占位资源。

## 后续变化

Version 2 已替代 TASK-011 中多项规则：

- 角色和装扮改为项目生成的二次元 2D 素材，不再使用 Fluent Emoji 3D 角色与装扮。
- 方形场景和装饰背景改为脚下椭圆地毯。
- 普通装扮不再按等级自动发放，改为键盘掉落或星星币兑换。
- 材料兑换和高级合成入口移除，历史合成记录继续保留。
- 星光碎片停止产出，历史余额可转换为星星币。
- 数据库继续升级到 v16（经济与桌宠偏好）和 v17（外观微调）。

当前规则见 [`../../DeskPet.md`](../../DeskPet.md) 和
[`../product/VERSION_2.md`](../product/VERSION_2.md)。
