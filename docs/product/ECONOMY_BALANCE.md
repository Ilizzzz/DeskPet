# Version 2 经济平衡

实际配置位于 `src/data/catalogs/economy.ts`。固定种子测试使用 `0x5eed1234` 抽取
100,000 次，要求每个物品的观察频率与公开概率相差小于 0.4 个百分点。

## 当前参数

- 每 1,500 次有效键盘按下掉落 1 件。
- 稀有度总概率：普通 60%、稀有 27%、史诗 10%、传说 3%。
- 分解收益：10 / 25 / 60 / 120 星星币。
- 直接兑换：80 / 180 / 450 / 1,000 星星币。
- 签到首个七日周期合计 250 星星币，平均约 35.7/日。
- 完成一次专注获得 2 星星币。

## 重复品期望收益

当掉落全部为重复品并全部分解时：

```text
60% × 10 + 27% × 25 + 10% × 60 + 3% × 120 = 22.35 星星币/次
```

| 使用形态 | 键盘次数 | 掉落节奏     | 仅重复分解的期望收益 |
| -------- | -------: | ------------ | -------------------: |
| 低频     |   500/日 | 约 3 日 1 件 |           约 7.45/日 |
| 常规     | 3,000/日 | 2 件/日      |           约 44.7/日 |
| 高频     | 9,000/日 | 6 件/日      |          约 134.1/日 |

常规用户若所有掉落均为重复品，只计算分解，兑换四档装扮约需 1.8、4.0、10.1、22.4 天；
若自然使用签到，约为 1.0、2.2、5.6、12.4 天。新用户前期的掉落主要扩充收藏，不会同时
快速收集和快速兑换。

## 收藏节奏

当前掉落池有 19 件。不分解最后一件时，期望不同物品数约为：

| 掉落次数 | 期望不同物品数 |
| -------: | -------------: |
|        2 |           1.92 |
|       14 |           9.08 |
|       30 |          13.38 |
|       60 |          16.57 |
|      180 |          18.74 |

后期重复率自然上升，为分解与心愿兑换提供来源；每件低概率物品也有确定的直接兑换路径。

## 调整约束

- 分解收益始终低于直接兑换价，禁止买入再分解刷币。
- 心愿不改变掉落概率，不自动消费。
- 成长纪念装扮第一次只随等级获得；分解后可按价格取回，不重复补发。
- 星光碎片不再产出，历史余额按 1:20 主动转换。
- 改动阈值、权重、价格或分解收益时，必须同步产品规则、界面、固定种子测试和本文。
