# Version 2 产品规则

本文解释 Version 2 的用户规则；精确常量以代码目录为准。

## 获得与成长

- 新账号获得默认小猫、透明地面和蓝色棒球帽。
- 伙伴、地毯、工具和五件成长纪念装扮按等级解锁。
- 普通装扮通过键盘掉落或星星币兑换获得，获得后即可穿戴，不需要再次购买或等级许可。
- 升级、专注、签到、成就和分解提供星星币；不新增星光碎片奖励。

## 键盘掉落

- 监听已启用时，每累计 1,500 次有效键盘按下掉落 1 件装扮。
- 鼠标点击参与统计和经验，不计入装扮掉落。
- 有效键盘按下和鼠标按下会立即触发不同桌宠动作；连续输入会刷新动作，不等待统计批次。
- 未满阈值的余数跨批次、日期和重启保存；一次批次可结算多次掉落。
- 掉落直接进入背包，不需要付费开启；每件物品概率在界面公开。
- 掉落为单次独立抽取，没有每日上限，也不应引导用户刻意刷键。

## 兑换、分解和心愿

- 基准兑换价：普通 80、稀有 180、史诗 450、传说 1,000 星星币。
- 分解收益：普通 10、稀有 25、史诗 60、传说 120 星星币。
- 默认保护每款最后一件；穿戴中的最后一件不能分解。
- 用户可明确关闭保护并确认分解最后一件；图鉴继续显示“曾获得”。
- 心愿只显示距离直接兑换还差多少星星币，不修改概率、不自动扣费。
- 历史星光碎片可按 1:20 主动转换；转换不可逆。

## 外观

- 9 个伙伴使用统一 256×256 透明画布：8 个动物伙伴采用二次元 2D 素材，“数学硕士”保留
  用户提供的原始头像；30 件装扮继续采用统一二次元 2D 素材。
- 装扮槽位为头部、颈部、面部、手持和背部。
- 默认位置由“伙伴槽位锚点 + 单件素材校正”计算。
- 用户可在外观页调整当前装扮的位置和大小；设置按伙伴和饰品分别保存，恢复默认不会影响
  其他组合。
- 场景只绘制脚下地毯；透明模式不增加地面物件。

## 迁移

- V1 等级、经验、统计、库存、穿戴、货币、碎片、领取记录和合成历史保留。
- 旧输入不追溯掉落，升级到 V2 后掉落进度从 0 开始。
- V1 普通装扮不因新规则重新发放；符合等级的 V2 纪念装扮幂等补领一次。
- 旧合成成就保留已领取状态；未完成目标改为可继续完成的收藏目标。

## 非核心候选

主题套装、每周收藏回顾和后续掉落池扩充不属于当前核心范围；新增内容必须同步概率、价格、
来源登记和测试。
