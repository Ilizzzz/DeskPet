# DeskPet 已知问题与发布检查

## 已知限制

- 安装包尚未代码签名，Windows SmartScreen 可能显示“未知发布者”；
- 首版只构建 Windows x64，不提供 ARM64 或其他系统版本；
- 异常强制终止时，最后一个尚未写入的约 5 秒统计批次可能丢失；
- 活跃时间来自聚合输入批次，是近似值，不是工时或考勤记录；
- 暂不包含自动更新、云同步和跨设备迁移；
- 桌宠拖动由主进程跟踪光标完成，8ms 周期移动窗口。极低性能机器或远程桌面环境下
  可能出现轻微跟随延迟；真实桌面拖动仍需手工验收；
- V2 地面使用 CSS 椭圆地毯，不含方形背景；透明边缘、25% 小尺寸和 125% 大尺寸仍需在
  不同 Windows DPI 下人工检查；
- 饰品使用“角色基础锚点 + 单件素材校正”，用户可按伙伴和饰品继续调整位置与大小；默认
  位置、用户微调在贴边动作和高 DPI 下的最终观感仍需真实桌面人工验收；
- 工具从 2 级起逐步解锁，低等级时部分工具不可用属于设计行为；
- 不会自动删除卸载后的用户数据，彻底删除方法见 [UNINSTALL.md](UNINSTALL.md)。

## 键鼠统计不可用时

1.1.1 起，统计启动失败不会影响桌宠和工具箱，应用会保持统计暂停并在设置页显示原因。

- 先在“设置 → 隐私与键鼠统计”点“重试启用”；
- 若仍失败，查看诊断日志 `%APPDATA%\DeskPet\input-diagnostics.log`（只记录平台、架构、
  资源路径和错误栈，不含键鼠内容）；
- 常见原因是杀毒软件拦截原生模块、系统策略禁止全局钩子，或安装文件不完整；
  可尝试重新安装 2.0.0、把 DeskPet 加入安全软件信任列表后重试；
- 发布构建请先运行 `npm run check:package`，并在项目目录之外复制应用目录运行
  `--input-hook-smoke-test`，避免开发机的 `node_modules` 掩盖打包缺失。

## 正式发布前仍需人工确认

- 在 Windows 10 和 Windows 11 干净环境实际安装、启动、升级和卸载；
- 真实键盘、鼠标、高权限窗口、锁屏和休眠/唤醒场景；
- 单屏、多显示器、五档宠物缩放、系统缩放比例、高 DPI、任务栏换边和显示器热插拔；
- 托盘、点击穿透、桌宠自定义拖动、单击/双击/右键、便签置顶和开机启动；
- 8 个角色 × 30 件装扮的默认位置、用户微调和恢复默认行为；
- 真实键盘掉落、暂停/重启进度、最后一件分解、星星币兑换和 V1 数据库升级；
- 跨日运行、长时间运行、CPU 与内存占用；
- SmartScreen 提示和后续代码签名方案。

自动化通过不代表以上桌面行为已经人工验收。
