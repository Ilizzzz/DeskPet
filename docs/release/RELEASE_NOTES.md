# DeskPet 发布说明

## 未发布：装饰微调、文档整理与新增伙伴

- 外观页增加装饰选择、四向位置调整、大小调整和恢复默认。
- 微调按“伙伴 + 饰品”分别保存，桌宠与控制中心预览共用同一结果。
- 数据库升级到 17 版，旧数据库自动创建 `item_adjustments` 表。
- 文档按开发、产品、设计、发布和法律重新分类；根文档改为当前事实。
- 删除已被当前基线替代的历史任务文档、过时预览和未引用的 V1 场景素材。
- 旧数据库迁移前自动创建版本化 SQLite 快照，等级、经验和累计经验保持不变。
- 新增 Lv.1 伙伴“数学硕士”：去除原头像边框和底色，保留原始头部并补绘写实身体；旧用户
  启动后自动补发，既有等级、经验和外观数据不变。

## 2.0.0：成长发现、二次元美术与桌宠交互

发布日期：2026-10-29

- 重做成长经济：每 1,500 次有效键盘按下必得 1 件装扮，19 件物品概率合计 100%，
  进度跨日、重启和批次持久化；控制中心公开当前概率和最近结果。
- 移除普通材料兑换和高级合成入口。常规装扮走掉落或星星币直接兑换，Lv.5/10/15/20/30
  分别获得独立纪念装扮；装扮获得后可直接穿戴，不再要求二次购买或等级许可。
- 分解按普通/稀有/史诗/传说返还 10/25/60/120 星星币，支持最后一件保护、曾获得图鉴、
  心愿目标和旧星光碎片 1:20 转换；旧合成成就改为可达成的收藏目标，已领取状态不变。
- 8 个伙伴和 30 件装扮换为统一的二次元 2D 透明素材，增加角色基础锚点与单件装扮微调；
  旧场景 ID 保留，但显示改为脚下椭圆地毯，不再使用方形背景。
- 新增五档宠物缩放（25%–125%，设置与托盘均可切换）、底部/左右边缘吸附及动作、键盘
  打字反馈、鼠标好奇反馈和掉落庆祝；输入反馈与总动画都可关闭。
- 数据库升级到 16 版。V1 等级、经验、统计、伙伴、场景、库存数量、穿戴、货币、碎片、
  成就和合成历史全部保留；掉落进度从升级后 0 开始，旧输入不追溯，纪念装扮幂等补领。
- 新增迁移、事务回滚、掉落边界、固定种子概率模拟、最后一件保护、缩放命中区等测试，
  并补充经济测算、生成提示词、透明网格拆分和美术来源登记。

## 1.1.2：控制中心一键卸载

发布日期：2026-10-28

- 控制中心“设置 → 安装与卸载”新增安装形态识别（安装版/免安装版/开发模式）和
  “打开程序目录”“打开数据目录”按钮。
- 安装版可在控制中心一键卸载：默认保留本地数据，也可选择“卸载并清除数据”
  （清除统计、成长、装扮、便签和设置），卸载由 Squirrel `Update.exe` 完成。
- 免安装版会在同一位置提示直接删除程序文件夹；开发模式显示无需卸载。
- 卸载前会停用键鼠监听、提交待写统计数据，并删除位置文件和诊断日志。
- 版本号 `1.1.2`；同时保留 1.1.1 的原生模块打包修复。

## 1.1.1：修复安装包原生模块缺失

发布日期：2026-10-28

- 修复 1.1.0 安装包在**其他电脑**上提示“键鼠监听不可用”的问题：Vite 打包会忽略
  `node_modules`，导致原生键鼠模块 `uiohook-napi` 没有被复制进安装包；开发机因为
  能找到项目仓库的 `node_modules`，原有 `--input-hook-smoke-test` 属于误报通过。
- 打包配置新增 `packageAfterCopy` 钩子，复制 `uiohook-napi` 与 `node-gyp-build`，
  并确认 `.node` 文件解包到 `resources/app.asar.unpacked`；新增
  `npm run check:package` 校验打包内容。
- 监听启动失败时改为**非阻塞提示**：统计保持暂停，桌宠和工具箱继续可用；
  失败原因写入 `%APPDATA%\DeskPet\input-diagnostics.log`，设置页会显示原因和“重试启用”。
- 托盘和设置页显示“统计不可用”状态，不再弹出错误框阻断启动流程。
- 安装包与免安装版均使用 `1.1.1` 版本号。

  单击显示台词气泡、双击打开控制中心、右键打开快捷菜单；
- 工具、伙伴、场景和装扮全部改为等级解锁；新增每日签到、12 个成就、
  材料兑换、14 条高级装扮配方、分解与收藏图鉴；
- 删除键鼠与专注的每日经验上限；专注新增星星币和星光碎片奖励；
- 新增待办清单、喝水提醒、倒计时、纪念日 4 个工具，工具总数达到 8 个；
- 控制中心 5 页重新设计，成长页提供等级环、分类解锁路线、下一个解锁、签到和成就；
  外观页包含实时预览、五槽位饰品、合成工坊与收藏图鉴；
- 数据库升级到 15 版，旧数据自动迁移（小狐狸 → 小老虎，旧装扮 ID → 新装扮 ID）；
- 更新 Windows 应用图标为新的猫咪配色；版本号 `1.1.0`。
