# DeskPet 安装与卸载

## 安装

运行 Squirrel 生成的 `DeskPetSetup.exe`，按 Windows 提示完成安装。安装包未签名时可能出现 SmartScreen 提示，应只使用项目可信构建产物。

## 卸载

### 方式一：控制中心一键卸载（1.1.2 起）

1. 右键桌宠打开控制中心，进入“设置 → 安装与卸载”；
2. 点击“卸载 DeskPet”（保留本地数据）或“卸载并清除数据”；
3. 确认后 DeskPet 会自动退出，Squirrel 卸载程序会删除程序文件和快捷方式。

“卸载并清除数据”会清除键鼠统计、成长等级、装扮、便签和设置；保留数据的卸载在重新安装后可以继续使用原有数据。

### 方式二：Windows 应用列表

在 Windows“设置 → 应用 → 已安装的应用”中找到 DeskPet 并选择卸载。

### 免安装版

直接删除解压出来的程序文件夹即可。用户数据仍保存在 `%APPDATA%\DeskPet`，可在控制中心“设置 → 本地数据”中重置，或手动删除该目录。

### 彻底清理用户数据

卸载程序默认保留本地用户数据。如果希望彻底清除：

1. 卸载前在 DeskPet 控制中心打开“设置与隐私”；
2. 选择“重置全部本地数据”，或直接使用“卸载并清除数据”；
3. 退出并卸载 DeskPet。

应用无法启动时，可在卸载后手动删除 `%APPDATA%\DeskPet`。删除前请先备份需要保留的便签或统计 CSV；该操作不可撤销。
