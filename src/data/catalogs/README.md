# 静态目录数据

存放角色、物品、场景、锚点、解锁、成长规则、经济、成就和工具元数据等应用预定义配置，
不存放用户运行数据。

- `appearance.ts`：9 个角色、30 件五槽位装扮、界面图标与资源列表。
- `scenes.ts`：透明桌面与 7 个椭圆地毯的主题配置。
- `anchors.ts`：每个角色五个饰品槽位的 256 画布锚点和单件素材校正；用户微调存于数据库。
- `unlocks.ts`：按等级汇总伙伴、场景、装扮和工具的解锁表。
- `growth.ts`：经验规则与等级奖励（不含每日上限）。
- `achievements.ts`：12 个成就定义。
- `economy.ts`：键盘掉落概率、装扮来源、兑换价格、分解收益和旧碎片转换规则。
- `tools.ts`：8 个工具的名称、图标、分类与解锁等级。

资源路径必须能被 `npm run validate:assets` 校验通过，新增素材前先阅读
`docs/design/ASSET_GUIDE.md`。
